# AGENTS.md「Issue の「確かめていないこと」…」の実例と実測

## 実測は2件、同じ引き継ぎの中に在る（#1050・#1113）

**実測は2件で、どちらも同じ日（2026-09-17）の同じ引き継ぎの中に在る。**

| Issue が書いていた逐語                                                                               | 確かめた結果                                                                                                  |
| ---------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| #1050「⛔ **その形は再現していない**」（例外を出さずに片方の書き込みが踏み消される真の lost update） | `FsPersonaStore` の `append` で再現した。**その PR でいちばん強い歯になった**（変異で赤くなることまで取れた） |
| #1113「**fs でプロセスを跨いだ競合を再現していない。**」                                             | 本物の2子プロセスを `spawn` して区間の重なりを測る歯にした                                                    |

**⟹ どちらも、確かめる前は「直したことの証拠」が無かった。** 確かめた後は、**実装を元へ戻すと赤くなる**という形で証拠が付いた。
