# AGENTS.md「テストを弱めずに直す」の実例と実測

#1192 の再編で AGENTS.md から逐語で移したもの。要約・短縮はしていない。規則そのものは AGENTS.md の同じ節に在る。規則を疑うとき・同じ形を踏んだかもしれないときに読む。

## 歯は、想定した理由とは違う理由で仕事をする（#285）

実例(2026-08-23、#285): 版のずれに備えて足した実行時の歯が、実際に捕まえたのは**実装ミス**だった — 網羅性チェック関数へ渡した `never` 型の変数を、そのまま本文として描いていた（画面に本文ではなく分岐キーの生の値が出る）。**型では捕まらない** — `never` も `string` も、`string` を要求する prop に代入できるからである。**この歯が無ければ、そのまま緑で通っていた。** 「たまたま助かった」ではなく「歯が在ったから捕まった」側である

## 「2回通しても壊れない」を測るテストが挟むべき状態（usage_daily_key_idx）

実例(2026-08-25、`usage_daily_key_idx`): `migrate` を2〜3回当てる歯が**3本在った**のに、**本番のデーモンが起動不能になった**（`could not create unique index … is duplicated`）。3本とも台帳の行が1つしか無い状態で2周目を通していて、**新しい鍵が許し古い鍵が拒む行**（同じ日・actor・モデル・層で `token_id` だけが違う行）を挟んでいなかった。挟むと3本とも赤くなる。逐語は `grep -Fn -- '「2回目は no-op」を約束しない' packages/storage-pg/src/migrate.ts`
