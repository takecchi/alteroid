実例: `apps/web/app/routes/` に「開いている PR」を出すコードは無いが、それは漏れではなく `packages/core/src/schema.ts` の `jobStatusSchema` の `lost` の doc が引く境界（**デーモンは PR もブランチも見に行かない**。リポジトリの事情はマネージャーの領域。逐語は `grep -Fn -- 'デーモンは PR もブランチも見に行かない' packages/core/src/schema.ts` で当たる）が守られている結果である。**⚠️ そしてこの結論は危うく壊れかけた。** 「PR が見えないのが放置の要因だ」という見立てから改修案を3つ人間へ並べたところ、**3案（クローンに PR 取得の道具を足す／日報に節を足す／委譲→PR を台帳へ積む）とも「デーモンに PR を見に行かせる」形で、この境界を壊すものだった。** 人間が「それでいこう」と言えば壊れていた — **「気づけた」ではなく「気づかなければ壊れていた」**
