# `.claude/agents-md-records/` とは

`AGENTS.md` は #1192 の再編（2026-09-27 のオーナー決定）で3層に分かれた。

- **(a) 判断基準** — 読まないと判断を誤るもの。`AGENTS.md` 本体に残る。
- **(b) 手順** — 特定の部分系を触るときだけ要る手順書・構成の説明・確認コマンド。`.claude/skills/` に在る（#1192 の PR1）。
- **(c) 実測記録・実例** — 過去の実測・実例・「実際にこう壊れた」の記録。**ここ（`.claude/agents-md-records/`）に在る**（#1192 の PR2）。

`AGENTS.md` に残る規則は、根拠になった実測・実例を失っていない——同じ節の中に、このディレクトリの対応するファイルへの1行のポインタがある。規則を疑うとき・同じ形を踏んだかもしれないときは、そのポインタを辿ってここを読む。

**移設は逐語である。要約・短縮はしていない**（north_star 禁止2。能力を削って軽さを実現しない）。移した内容が失われていないことは、`AGENTS.md` の旧版（`git show 97bcb44:AGENTS.md`）とこのディレクトリの現物とをチャンク単位で突き合わせて確かめてある（`node tools/check-preserved.mjs <repo> 97bcb44` が MISSING: 0 を返す）。
